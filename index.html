Teto Transcriber, the bot in our server

Join the Discord server and you can use the bot right away. It turns a song into a playable piano MIDI file.

Run /transcribe in the teto-bot channel, then choose one option:

file
MP3, WAV, FLAC, OGG or M4A, up to 50 MB
url
A SoundCloud link or a direct audio link
limits
Piano only, 50 MB maximum, 40 minutes maximum

Type /help to see every command.

A small home for MIDI.

tetomidi puts everything we make with MIDI in one place: a community on Discord, a player that shows every note on a piano roll, an editor to write your own MIDI, and tools that turn recordings into MIDI.

Discord server

Share songs and MIDI files, ask questions and meet other players. The Teto Transcriber bot lives here: type /transcribe in the teto-bot channel to turn a song into a piano MIDI file.

From song to piano roll

  1. Send your song to the Discord bot, or upload an MP3 to the MP3 to MIDI tool.
  2. Download the MIDI file you get back.
  3. Drop it into the MIDI player and press Play.
